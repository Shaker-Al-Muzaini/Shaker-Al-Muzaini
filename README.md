## About

I build Laravel APIs, FastAPI services, and n8n workflows. My work connects business systems, AI integrations, and cloud deployment, with human review where it matters. **Open to freelance** projects in backend development and automation.

## What I do

- Build APIs, authentication, billing, queues, and real-time features.
- Integrate AI services for summaries, transcription, translation, and dubbing.
- Automate research, approvals, publishing, and archiving with n8n.
- Deliver containerized applications with Docker, GitHub Actions, and AWS.
